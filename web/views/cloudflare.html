Angka diambil dari GraphQL Analytics API Cloudflare dan disimpan sementara 5 menit (tombol Muat ulang mengambil data terbaru). Tanggal mengikuti UTC (hari Cloudflare berganti jam 07.00 WIB), periode dihitung per bulan kalender.

Proyeksi = pemakaian sejauh ini + rata-rata 3 hari terakhir × sisa hari bulan ini, jadi lonjakan langsung terlihat di proyeksi. Kuota & harga lebih mengikuti paket Workers Paid ($5/bulan). Observability hanya perkiraan minimal (1 event per request, belum termasuk console.log), karena Cloudflare tidak menyediakan angkanya lewat API ini.
