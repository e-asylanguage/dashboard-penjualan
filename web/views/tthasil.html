Memuat…

Dana dicairkan = Jumlah penyelesaian pembayaran (settlement) = pendapatan + biaya TikTok + penyesuaian. Pendapatan = subtotal setelah diskon penjual dikurangi pengembalian dana.

Biaya TikTok = biaya platform (komisi, layanan Mall/Growth Xtra, komisi dinamis, pemrosesan pesanan) + ongkir & layanan logistik + komisi afiliasi + pajak (PPh 22).

Laba kotor = dana dicairkan − HPP. HPP = isi pesanan × HPP Manajemen SKU saat ini, hanya untuk pesanan yang barangnya terjual. Biaya iklan belum dikurangi.

Data dari upload file dan sinkron API digabung per Order ID — pesanan yang sama tidak dihitung dua kali.
