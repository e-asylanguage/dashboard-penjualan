Memuat…

Hanya user di daftar ini yang bisa login (selain akun peninjau Shopee). Minimal satu admin aktif selalu dijaga: admin terakhir tidak bisa dihapus, dinonaktifkan, atau diturunkan aksesnya.

Admin = bisa membuka semua menu, mengubah data, dan mengelola user. User biasa hanya melihat menu yang dicentang; menu lain hilang dari sidebar dan datanya ditolak server.

Hanya lihat = tombol upload, tambah, ubah, hapus, dan sinkron disembunyikan, dan server menolak semua perubahan. Boleh ubah = bisa mengubah data di menu yang dicentang.

Setiap user bisa mengganti passwordnya sendiri lewat menu akun di bawah sidebar (klik nama akun) › Ganti password.
